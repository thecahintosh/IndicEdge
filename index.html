File support, calculation rules and privacy
Supported: PDF with a text layer, Word DOCX, UTF-8/UTF-16 TXT, Markdown/log text, CSV/TSV, JSON/JSONL, and XLSX. Up to 5 MB, 5,000 records and 200 columns. PDFs are limited to 100 pages. Scans/images need OCR; legacy DOC/XLS and encrypted files need conversion to a supported format.
Documents become line/paragraph records. DOCX tables are selectable separately and use their first row as headers. Business columns are never guessed from prose; extraction and layout limitations are shown above the preview. CSV/TSV and XLSX require one header row; JSON records use their own field names.
Numeric operations accept decimal values with up to six decimal places. Missing cells are reported; mixed/non-numeric fields block numeric calculations rather than silently losing values. Source files and extracted text remain in browser memory; no document is sent to a model. Exported CSV protects against spreadsheet formula injection.
Order reminders still require order_id, customer_name, contact, due_date, amount and status, with valid values and up to 2,000 orders. A financial ledger or document can load and be analyzed without these fields. Financial transaction dates are not assumed to be order due dates.

Why this workflow uses the CPU
Order filtering, date comparisons, integer money arithmetic and reminder templates are deterministic operations. This build uses browser CPU execution for them. A detected GPU is availability information; no CUDA workload is claimed.
Prune evidence
Optional AI calls require approval. Their returned metadata is saved in run history. A signature is shown as present or absent; this app does not claim cryptographic verification. Estimated gateway savings are distinct from actual charged cost.

Fields used for retrieval
Only selected fields enter the local index. Common contact, banking and confidential field names start excluded. Document text can still contain private facts. Review excerpts before sharing.
Retrieval limits and privacy
Up to 8 sources, 4 million indexed characters and 10,000 passages. Sources and the local index stay in browser memory. Uploading the same file name replaces its retrieval copy. Re-add an active-source snapshot after changing its records. Clearing the analysis source does not clear these independent copies; use Clear retrieval files, sign out or reload.
Search uses source words, not semantic embeddings. Use the source language. Relevance scores are not confidence. For totals over an entire dataset, use Source data → Analyze fields; selected excerpts may omit necessary rows.
AI answers require an approved, pattern-redacted question and selected excerpts routed through Prune. File names and full sources are excluded. Citation IDs are validated, but factual correctness is not guaranteed.
