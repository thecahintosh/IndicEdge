# IndicEdge
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Small-business owners reviewing overdue orders and preparing Hindi/English customer reminder drafts. Hackathon judges need a complete, inspectable demonstration.

## Product Purpose
Convert a supported everyday instruction into a validated reusable workflow. Process fresh records with minimal external disclosure and auditable model usage.

## Capabilities and Constraints
Ask your files provides browser-local BM25 retrieval across up to eight sources, with field selection, bounded passages and file/page/paragraph/row citations. Optional generated answers send only an explicitly approved question and selected redacted excerpts through Prune; source-ID validity is checked independently. This does not guarantee factual grounding or semantic/cross-language matching. Retrieval copies remain in browser memory and can be cleared separately from the analysis source.
Sources can have arbitrary schemas. CSV/TSV, JSON/JSONL and XLSX datasets load locally, with per-operation missing-field/invalid-value notes. PDF text layers, Word DOCX body text/tables and UTF-8/UTF-16 plain text also load locally into inspectable records. Generic local operations include profiling, count, numeric aggregates, filters, sorting, grouping and named cash-flow summaries. These operations are separate from the bounded order-reminder plan, which retains its original schema and approval rules. Import limits are 5 MB / 5,000 records / 200 columns; order execution is capped at 2,000 orders. Document extraction is not OCR or semantic RAG, and does not infer absent business fields.
Existing vanilla HTML/CSS/JavaScript, Express, Supabase Auth, Drizzle/PostgreSQL and Prune are retained. Every remote generative call goes through Prune. Customer messaging remains draft/export only. Local means the backend runs on the user's machine; remote hosting does not make uploaded data local. GPU availability must not be described as acceleration.

## Brand Commitments
User requested a black, minimalist interface with motion animations. Preserve the IndicEdge name and honest product claims.

## Product Principles
- A proposed plan never grants its own data access.
- Approve exact minimized data before remote processing.
- Reuse instructions with current records and current validation.
- Prefer deterministic code for dates, money, filtering and templates.
- Show actual outcomes, provider metadata and limitations.
